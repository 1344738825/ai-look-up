# AI Look-Up (ai-look-up)

让 AI 在长时间空跑时**中途自我审查**的 ZCode 插件。

AI 长任务里最常见的浪费不是做错,而是**空跑**:换名字重跑同一个探针脚本、盲目重试失败的命令、一两个小时只跑不改却毫无产出。本插件通过会话钩子持续观察 AI 的行为节奏,命中空跑特征时向对话注入「抬头」提醒,让 AI 及时停下来对照目标、检查近几步是否带来新信息、决定继续 / 换方法 / 汇报。

检测维度:完全相同的命令原样重复、换汤不换药的相似命令(文件名序号归一化,`_peek2.py` ≈ `_peek3.py`)、超长零产出、调用密集零产出、失败循环;同一会话提醒 3 次无效后自动升级语气。

## 安装(插件市场方式)

克隆本仓库后,在 ZCode 中打开 **插件市场 → 添加 → 添加插件市场**,选择本仓库目录(或粘贴其本地路径),然后在 **个人 → ai-look-up-market** 中安装「AI 抬头」。

## 手动安装

把 [`ai-look-up/`](./ai-look-up) 目录复制到 ZCode 的插件目录,或参照 [ai-look-up/README.md](./ai-look-up/README.md) 中的说明配置。

详细文档(检测原理、阈值配置、排错)见 [ai-look-up/README.md](./ai-look-up/README.md)。
